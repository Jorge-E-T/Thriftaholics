Data & backups

Your data lives only in this browser’s IndexedDB, encrypted with your password. Back up regularly — clearing browser data or losing your password erases it.

☁ Cloud sync

Keeps every phone and computer in step within seconds. Everything is encrypted with your app password before it leaves this device, so the cloud only stores scrambled data. Use the same app password on every device. Photos sync as smaller copies. Setup steps are in the Cloud Sync Setup Guide.

Safety snapshots

A restore point (inventory, expenses, settings) is saved automatically before every import or restore and before you first use a new version of the app. The last 10 are kept, encrypted, on this device. Restoring one keeps photos attached.

Import from another program

Restore / Import JSON accepts backups from other inventory programs too. You map the old fields once, and the app remembers the format, so later imports take one click. Records imported again are updated instead of duplicated.
